# Project Notes

## Project Type
Sales analytics and business intelligence dashboard.

## Primary Stack
- SQL / MySQL
- Power BI
- DAX
- Power Query

## Recommended Review Flow

1. Review the SQL dataset and queries.
2. Open the Power BI report.
3. Review the data model and relationships.
4. Inspect KPI measures and dashboard visuals.
5. Validate that the dashboard supports the stated business questions.

## Public Repository Checklist

Before publishing database files, remove:

- Local machine-specific connection strings
- Database usernames/passwords
- API keys or tokens
- Private customer information
- Environment-specific paths

The Power BI `.pbix` file can be uploaded manually through GitHub if binary upload is required.
